# Anom

Anom reads your books aloud. Open a PDF, Word (.docx), EPUB or text file, press play, and every word lights up as it is spoken.

- Tap any word to start reading from there
- Speed button: 0.9x to 2x (starts at 1.3x)
- Contents list for chapters
- Remembers where you stopped

It is one static page (`index.html`) with no build step. Voices come from the reader's own device.

## Deploy on Vercel
Import this GitHub repo in Vercel, keep the framework as "Other", and press Deploy.
